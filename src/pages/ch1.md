## บทที่ 1 เบื้องต้น

การที่คอมพิวเตอร์จะทำงานได้นั้น ผู้ที่สนใจในด้านการเขียนภาษาคอมพิวเตอร์ จะต้องมีความเข้าใจในสถาปัตยกรรมคอมพิวเตอร์ และวิธีการออกแบบภาษาคอมพิวเตอร์ จึงจะสามารถเข้าใจได้ว่าทำไมภาษาโปรแกรมจึงเป็นส่วนสำคัญในการพัฒนาโปรแกรม รวมไปถึงปัญหาที่พบเจอจากการทำงานร่วมกันระหว่างคอมพิวเตอร์ นั่นก็คือการเขียนโดยใช้ความสามารถของภาษาโปรแกรมเพื่อแก้ปัญหาในเชิงหลักการและความถูกต้อง แต่แลกมาด้วยความซับซ้อนของตัวโปรแกรม 

ดังนั้นในวิชานี้จะได้เรียนหลักการและเหตุผลว่าในแต่ละภาษาถูกออกแบบมาเพื่อช่วยนักพัฒนา สามารถดึงศักยภาพของตัวภาษามาใช้ให้เกิดประโยชน์สูงที่สุด

เมื่ออ้างอิงจากตำรา ***Concepts of Programming Languages (12th ed.) โดย Sebesta*** ได้ให้หลักแนวคิดถึงความจำเป็นในการเรียนภาษาโปรแกรมดังนี้ (Sebesta, 2019, หน้า 2-4)
### เหตุผลที่ควรจะเรียนภาษาโปรแกรม

- **เพื่อเพิ่มศักยภาพในการแสดงออกทางความคิด** การที่คนเราจะสือสารได้นั้นจะต้องสามารถเข้าใจภาษาในการสื่อสาร นั่นก็คือ ฟัง, พูด, อ่าน และเขียน การที่จะถ่ายทอดความคิดออกมาทางภาษา จะต้องมีความเข้าใจในตัวโครงสร้างของภาษา จะสังเกตุได้ว่า คนที่เข้าใจโครงสร้างภาษา จะมีลำดับการคิดเป็นระบบและสามารถ ถ่ายทอดความคิดได้ดีกว่า คนที่ไม่เข้าใจในตัวโครงสร้างของภาษา โปรแกรมเมอร์ส่วนใหญ่ก็มักจะพบเจอปัญหาเดียวกัน นั่นก็คือความซับซ้อนของภาษา เช่น control structures, data structures เป็นต้น การที่มีความเข้าใจว่าในแต่ละภาษาโปรแกรมมีคุณสมบัติอะไรบ้าง ทำให้เราสามารถที่จะเขียนโปรแกรมได้อย่างหลากหลายมากขึ้น เช่นภาษา C ไม่รองรับการใช้ associative arrays เหมือนในภาษา Perl แต่เมื่อเราเข้าใจและมีความต้องการอยากจะใช้งาน associative arrays ได้นั้น เราสามารถที่จะสร้างเลียนแบบ associative arrays ขึ้นมาในภาษา C ได้ ซึ่งเป็นการเสริมสร้างหรือต่อยอดความสามารถในภาษานั้นขึ้นมา
- **มีความรู้เชิงลึกในการเลือกใช้ภาษาโปรแกรมได้อย่างเหมาะสม** เนื่องจากในหน่วยงานมีการใช้ภาษาโปรแกรมเพียงไม่กี่ภาษา และเมื่อเวลาผ่านไปหลายๆปี มีความต้องการพัฒนาระบบใหม่ๆ นักพัฒนาในหน่วยงานนั้น ไม่ได้เลือกใช้ภาษาใหม่แต่ยังคงใช้ภาษาที่คุ้นเคยอยู่ จึงทำให้ไม่สามารถแก้ปัญหาบางอย่างได้ เนื่องจากภาษาที่ใช้มีขีดความสามารถที่จำกัด ทำให้บางครั้งต้องมีการเขียนโปรแกรมเพิ่มเติม หรือใช้ Library เพื่อจำลองการทำงานบางอย่างที่ภาษานั้นๆ ไม่สามารถทำได้ จึงเกิดผลเสียมากมายตามมาทีหลัง
- **เพิ่มศักยภาพในการเรียนรู้ภาษาใหม่** การที่จะเรียนรู้ภาษาโปรแกรมจะต้องมีความเข้าใจวิธีการออกแบบ, การใช้เครื่องมือ และยิ่งตัวภาษาเองนั้นยังมีการปรับปรุงอย่างต่อเนื่อง เช่นคนที่มีความเข้าใจในการเขียนโปรแกรมเชิงวัตถุ ก็จะสามารถเข้าใจการเขียนโปรแกรมด้วยภาษา Ruby ได้มากกว่าคนที่ไม่เคยเรียนมาเลย ถ้าเปรียบคนที่สามารถเข้าใจภาษาไทย และสามารถเรียนภาษาอังกฤษเพิ่มอีกหนึ่งภาษาได้ ก็จะเห็นได้ว่าโครงสร้างภาษาของภาษาไทยและภาษาอังกฤษ มีโครงสร้างทางภาษาที่ไม่เหมือนกันเลย มีหน่วยงาน TIOBE Programming Community ที่เป็นชุมชนได้รวบรวมภาษาโปรแกรมที่เป็นที่นิยมในแต่ละปี ทำให้เราได้รับรู้ว่าภาษาที่เป็นที่นิยมนั้น คือภาษาอะไร และภาษานี้ถูกนำไปใช้ในเรื่องอะไร และที่สำคัญที่สุดนั่นก็คือความสามารถในเรื่องของคำศัพท์ และความรู้พื้นฐานของการเขียนโปรแกรม จะส่งผลต่อการอ่านและการเขียนโปรแกรม และยังลงลึกไปถึง compilers ได้อย่างดียิ่งขึ้นด้วย
- **เข้าใจถึงความสำคัญของการนำไปใช้** ในการเรียนภาษาโปรแกรมจะต้องรู้ถึงความสำคัญของหลักการและเหตุผล และผลลัพธ์ที่ได้จากการนำไปใช้ ว่าในแต่ละภาษาได้ถูกออกแบบมาเพื่อช่วยแก้ปัญหาในโปรแกรมได้อย่างไร ซึ่งข้อผิดพลาดบางอย่าง อาจจะเกิดจากไม่เข้าใจคำสั่งในตัวภาษาโปรแกรมนั้นๆ เช่น โปรแกรมเมอร์ที่มีความรู้น้อย มักจะดีไซน์ฟังก์ชั่นขึ้นมาหนึ่งฟังก์ชั่น และถูกเรียกใช้งานบ่อยครั้ง ทำให้มีประสิทธิภาพลดลงได้ เช่นมีการจัดการหน่วยความจำใน Stack อยู่บ่อยครั้ง เมื่อมีการเรียกใช้เพื่อเก็บค่าของตัวแปรที่ถูกส่งต่อ เป็นต้น
- **เข้าใจตัวภาษาโปรแกรมที่รู้อยู่แล้วได้ดียิ่งขึ้น** ภาษาโปรแกรมสมัยใหม่ มักจะมีขนาดที่ใหญ่และมีความซับซ้อน จึงเป็นไปไม่ได้ที่เราจะเข้าใจขีดความสามารถทั้งหมดที่ตัวภาษานั้นสามารถทำได้ การที่เราเรียนวิชานี้ ทำให้เข้าใจหลักการและความสามารถบางอย่างที่ไม่เคยรู้และไม่เคยใช้มาก่อน และทำให้เริ่มลองใช้งานความสามารถเหล่านั้น
- **มุมมองของการนำไปใช้** การที่ภาษาใดภาษาหนึ่งมีคนใช้เยอะ ไม่ได้หมายถึงว่าภาษานั้นจะดี ภาษานี้อาจจะดีเฉพาะบางอย่างก็ได้ และการที่เลือกใช้ภาษานั้นๆ ก็อาจจะเพราะยังไม่รู้จักภาษานั้นดีพอก็ได้ เช่นในสมัยก่อนมีคนอยากให้ใช้ภาษา ALGOL60 มากกว่า Fortran เพราะเชื่อว่า Fortran มีความซับซ้อนน้อยกว่ามี การใช้ Control Statement เพิ่มเข้ามา ซึ่งคนในสมัยนั้นกลัวที่จะใช้เพราะไม่เข้าใจหลักการดีไซน์และการทำงาน ซึ่งค่อนข้างเข้าใจยากเช่นการใช้ block structure, การใช้ recursion หรือการใช้ Control Structure อย่าง If-Else และ While-Loop เป็นต้น  

### หลักเกณฑ์ในการพิจารณาภาษา

หากจะพิจารณาถึงความสามารถของภาษาโปรแกรม ก็จะพิจารณาถึงปัจจัยที่ส่งผลต่อกระบวนการพัฒนาโปรแกรม ซึ่งจะประกอบไปด้วยหลักเกณฑ์ใหญ่ๆ 3 หลักเกณฑ์โดยสามารถดูได้จากตาราง 1.1 ด้านล่างนี้
#### 1. Readability

สิ่งสำคัญที่สุดในการตัดสินว่าภาษาโปรแกรมใดง่ายต่อการอ่านและทำความเข้าใจ เมื่อย้อนกลับไปก่อนปี ค.ศ. 1970 การพัฒนาโปรแกรม จะมุ่งเน้นไปที่การเขียนโปรแกรมให้มีประสิทธิภาพโดยอิงจากตัวอุปกรณ์คอมพิวเตอร์มากกว่าผู้ใช้งานทั่วๆไป ต่อมาในยุคปี ค.ศ. 1970 ได้มีการคิดค้น ***Software Life-cycle โดย (Booch, 1987)*** ได้มองว่าการเขียนโปรแกรมเป็นส่วนเล็กๆ และให้ความสำคัญกับการบำรุงรักษาซะเป็นส่วนใหญ่โดยพิจารณาจากทรัพยากรที่ใช้ไป โดยการบำรุงรักษาจะทำได้โดยการพิจารณาจากความสามารถในการอ่านโค๊ดของตัวโปรแกรม ซึ่งบ่งบอกถึงคุณภาพของตัวโปรแกรมและภาษาโปรแกรมที่ใช้
